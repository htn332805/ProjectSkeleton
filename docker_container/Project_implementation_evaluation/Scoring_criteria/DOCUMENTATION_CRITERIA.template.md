# DOCUMENTATION_CRITERIA
 Scoring rubric for documentation.
 > Detailed scoring criteria for documentation quality.
>
> Goal: provide a consistent rubric for evaluating documentation with evidence.

---

## 1) How to use this rubric

- Score each criterion from 1–5 using the shared scale in:
  - `/Project_implementation_evaluation/Scoring_criteria/PROJECT_EVALUATION_SCORE.md`
- Provide evidence links for each score.
- If evidence is missing, score conservatively.

## 2) Criteria and scoring

### D1) Accuracy (docs match behavior)
What to look for:
- Docs reflect current code and contracts
- Examples/tutorials still work
- API reference matches implementations

Scoring hints:
- 5: Minimal drift; examples run; doc checks catch issues.
- 3: Core docs are correct; some drift in examples/details.
- 1: Docs frequently misleading; users rely on source code.
