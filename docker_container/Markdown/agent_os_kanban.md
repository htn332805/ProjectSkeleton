### 3\. The Human-in-the-Loop Gate

The "Gate" at Floor 3 is the most critical modification from earlier iterations of the Hermes system. It solves the problem of "blind" execution by ensuring the agent's understanding aligns with the user's intent.

* **The Planning Phase:** Before building, the agent writes a full plan including the approach, target keywords, internal linking strategies, and specific milestones.
* **Approval/Rejection:** The user can read the plan in approximately 20 seconds.
  * If the plan is incorrect or misses an angle, the user **rejects** it, forcing the agent to replan (a "cheap fix" compared to fixing a finished product).
  * If the plan is correct, the user hits **approve**, and the agents begin the build.
* **Autonomy:** After approval, the user does not need to "babysit" the system or watch a terminal; the agents work independently.

### 4\. Obsidian Memory Vault Integration

The system is integrated directly into an Obsidian vault, functioning as a "Second Brain" for the agent system. This integration addresses the problem of losing context or "forgetting" ideas.

* **Persistent Logging:** Every project, idea, and plan is written into the Obsidian memory log as it happens.
